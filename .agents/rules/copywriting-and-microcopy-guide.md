# ✍️ FitPro - Copywriting & Microcopy Guidelines

**Target AI:** Antigravity (Senior Technical Partner)
**Objective:** Define the strict language rules, tone of voice, and psychological triggers for all text, labels, notifications, and dummy data generated within the FitPro app.

---

## 1. Strict Language Requirement (pt-BR)

- **Brazilian Portuguese Only:** ALL user-facing text, placeholders, error messages, notifications, and mock data MUST be generated in natural, fluent Brazilian Portuguese (pt-BR).
- **Culturally Accurate:** Avoid robotic or literal translations from English. Use natural Brazilian phrasing (e.g., use "Bora treinar!" instead of a literal "Let's train!").

## 2. The Persona (Voice & Tone)

- **The Premium Personal Trainer:** The app's voice should sound like a high-end, exclusive, and highly motivational personal trainer.
- **Authoritative yet Empathetic:** Speak with absolute authority on fitness and health, but show deep empathy for the user's daily struggles and fatigue.
- **Action-Oriented:** Always start instructions and Call-to-Actions (CTAs) with strong, positive action verbs (e.g., "Transforme", "Supere", "Conquiste", "Começar").

## 3. Sales Psychology & Conversion Copy

Whenever generating text for paywalls, checkouts, or premium features, Antigravity must apply these triggers:

- **Value over Features:** Don't just list what the app does; sell the transformation. (Instead of "Acesso a 50 treinos", write "O atalho exato para o seu corpo ideal com 50 treinos exclusivos").
- **Social Proof:** Write copy that builds community trust. (e.g., "Junte-se a mais de 10.000 alunos", "O treino mais bem avaliado da semana").
- **Urgency & Scarcity:** For promotional components, create ethical FOMO (Fear Of Missing Out). (e.g., "Oferta destravada apenas pelas próximas 24h", "Últimas vagas para o Desafio 30 Dias").

## 4. Behavioral Microcopy & Habit Formation

- **Frictionless Labels:** Keep button texts and form placeholders extremely short and clear to reduce cognitive load.
- **Positive Loss Aversion:** Use loss aversion carefully on cancellation or downgrade screens. (e.g., Instead of "Cancelar assinatura", use "Interromper minha evolução" or "Quero abrir mão dos meus resultados").
- **Gamification & Celebration:** Celebrate user streaks and achievements enthusiastically to release dopamine. (e.g., "Incrível! Você bateu sua meta por 5 dias seguidos. O shape tá vindo!").

## 5. Handling Errors & Edge Cases

- **Zero Guilt for Missed Workouts:** If a user breaks a streak or misses a day, never use negative or guilt-tripping language. Frame it positively: "O descanso faz parte do processo. Seu próximo treino já está te esperando!"
- **Friendly Error Messages:** Never make the user feel stupid. Instead of "Senha inválida" or "Você errou o email", use "Ops! Parece que essa senha não bateu. Vamos tentar de novo?".
